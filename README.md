# Character AI Studio (Python)

A Python, local-first AI roleplay and storytelling application inspired by the public feature set of [LettuceAI/app](https://github.com/LettuceAI/app).

This repository is an independent Python implementation. It does **not** copy LettuceAI source code. The design is based on publicly visible product behavior and architecture-level descriptions: local-first chat, custom characters, memory, model/provider configuration, prompt templates, image prompt workflows, and optional text-to-speech hooks.

## Implemented in this Python version

- Local-first data storage with SQLite
- Character creation and editing
- Chat sessions and message history
- Long-term memory records and context summaries
- Provider/model configuration
- OpenAI-compatible chat completion client
- Ollama-compatible local model client
- Image generation request records and prompt workflow
- System prompt templates with variables
- FastAPI backend with autogenerated API docs
- Minimal web UI served by FastAPI

## Run

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open:

- Web UI: http://127.0.0.1:8000
- API docs: http://127.0.0.1:8000/docs

## Configuration

Create `.env` from `.env.example`:

```bash
cp .env.example .env
```

Supported provider modes:

- `openai_compatible`: any OpenAI-compatible HTTP API
- `ollama`: local Ollama server
- `mock`: deterministic local mock responses for development
